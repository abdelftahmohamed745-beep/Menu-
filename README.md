# منصة المنيو الرقمي وقوائم الطعام للمطاعم (Menu QR)

تطبيق متكامل لإدارة واستعراض قوائم الطعام الرقمية للمطاعم والكافيهات مع دعم رموز الاستجابة السريعة (QR Code)، ولوحة تحكم مخصصة لكل مطعم، وبوابة إدارة عامة للمنصة (Super Admin Portal).

---

## المميزات الرئيسية

- **منيو رقمي سريع ومتجاوب:** تصميم عصري متوافق مع كافة أحجام الشاشات والجوال، مع دعم كامل للغة العربية (RTL).
- **إدارة متعددة المطاعم:** معرّف ثابت لكل مطعم (Internal ID) واسم رابط علني قابل للتغيير (Slug) مع حفظ الروابط القديمة وإعادة توجيهها تلقائياً.
- **أمان عالي للخادم:**
  - تسجيل دخول للإدارة العامة عبر متغير البيئة `SUPER_ADMIN_PASSWORD` مع مقارنة آمنة زمنياً وحماية ضد هجمات القوة الغاشمة (Rate Limiting).
  - كلمات مرور مشفرة لكل مطعم (PBKDF2/SHA-256) مع ترقية تلقائية لكلمات المرور القديمة.
  - دعم الروابط السحرية السريعة (`/r/:token`) للدخول إلى لوحة التحكم بنقرة واحدة.
  - جلسات مشفرة وتوقيع ملفات تعريف الارتباط عبر `SESSION_SECRET`.
  - التحقق المباشر من خلال Firebase Admin SDK على الخادم مع حماية قواعد البيانات.

---

## المسارات والواجهات

| المسار | الوظيفة |
|---|---|
| `/` | الصفحة الرئيسية للمنصة والبحث المباشر عن مطعم عبر المعرّف |
| `/menu/:slug` | منيو المطعم للزبائن مع استعراض الأقسام والوجبات والفلترة |
| `/admin/:restaurantId` | لوحة تحكم صاحب المطعم لتعديل الأصناف والأسعار وبيانات المطعم |
| `/super-admin` | بوابة الإدارة العامة للمنصة لإدارة المطاعم وتوليد الروابط وفحص النظام |
| `/r/:token` | معالجة الروابط السحرية للدخول المباشر |

---

## نقاط فحص الخادم (API Health & Diagnostics)

- `GET /api/ping`: فحص استجابة الخادم السريع وعرض رقم إصدار البناء الحالي (`BUILD_ID`).
- `GET /api/health`: فحص حالة دوال الخادم وحالة الاتصال بقاعدة بيانات Firebase Admin.
- `GET /api/public/menu/:slug`: تحميل قائمة المطعم بسرعة فائقة مع التخزين المؤقت على شبكة التوصيل CDN.
